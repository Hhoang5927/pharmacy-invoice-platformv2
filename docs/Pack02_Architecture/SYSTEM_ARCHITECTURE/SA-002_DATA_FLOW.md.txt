# 1. Purpose

This document defines how data flows through the Pharmacy Invoice Automation System.

The objective is to ensure that data moves in a predictable, traceable and auditable manner between all system modules.

---

# 2. Data Flow Principles

The system shall follow these principles:

- Data flows in one direction.
- Each module has a single responsibility.
- Each module produces a defined output.
- Modules never modify outputs produced by previous modules.
- Approved data is immutable.

---

---

# 9. Approved Dataset

Approved Dataset becomes the only trusted business data.

Previous stages become read-only history.

Automation shall consume only Approved Dataset.

---

# 16. Success Criteria

The data flow is successful when:

- Every stage completes successfully.
- Every transition is recorded.
- No data loss occurs.
- Approved Dataset remains unchanged.
- Browser Automation completes successfully.
