# 1. Purpose

This document defines the architecture of the Human Review Module.

The Human Review Module provides an interface for reviewing, correcting and approving extracted invoice data before browser automation begins.

The Human Review Module is the only module allowed to modify extracted business data after AI processing.

---

# 2. Responsibilities

The Human Review Module shall:

- Display extracted invoice
- Display validation results
- Highlight validation errors
- Allow business corrections
- Approve invoices
- Reject invoices
- Generate Approved Dataset

---

# 3. Design Principles

Human decisions override AI decisions.

Every modification shall be audited.

Approved data becomes immutable.

Automation shall only use approved data.

---
