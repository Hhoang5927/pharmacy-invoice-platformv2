# 1. Purpose

This document defines the architecture of the Browser Automation Engine.

The Automation Engine is responsible for executing browser interactions using the Approved Dataset.

Automation is an execution layer only.

It never performs business validation or business decisions.

---

# 2. Responsibilities

The Automation Engine shall:

- Launch browser
- Authenticate user session
- Navigate the pharmacy website
- Enter invoice information
- Enter purchase items
- Save invoice
- Verify saved data
- Generate execution report

---

# 3. Design Principles

Automation shall:

- Use only Approved Dataset
- Execute deterministic actions
- Stop on critical failures
- Record every action
- Support retry for recoverable failures

Automation shall never:

- Modify business data
- Skip validation
- Ignore errors
- Continue after critical failures

# 5. Components

## Execution Manager

Responsibilities

- Manage execution lifecycle
- Control execution order
- Coordinate internal components

---

## Browser Manager

Responsibilities

- Launch browser
- Close browser
- Manage browser instance
- Manage browser context

---

## Session Manager

Responsibilities

- User login
- Session validation
- Session recovery
- Session expiration detection

---

## Navigation Engine

Responsibilities

- Navigate menus
- Open purchase invoice screen
- Wait for page readiness
- Handle page transitions

---

## Form Engine

Responsibilities

Enter:

- Supplier
- Invoice Information
- Purchase Items
- Batch
- Expiry
- Purchase Price
- VAT

One completed row before processing the next.

---

## Verification Engine

Responsibilities

Verify:

- Supplier
- Invoice Number
- Invoice Date
- Purchase Item Count
- Saved Status

Verification occurs immediately after saving.

# 7. Retry Strategy

Retry permitted for:

- Network interruption
- Page timeout
- Temporary browser failure

Retry prohibited for:

- Business validation failures
- Missing required fields
- Verification mismatch

Retry count shall be configurable.

---

# 8. Error Recovery

Recoverable Errors

- Slow page loading
- Temporary network issue
- Browser crash

Non-Recoverable Errors

- Invalid Approved Dataset
- Authentication failure
- Missing UI element
- Verification failure

---

≤ 60 seconds

- Browser launches successfully.
- User session is valid.
- Invoice is entered correctly.
- Verification passes.
