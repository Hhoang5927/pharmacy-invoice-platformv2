# 1. Purpose

This document provides an overview of the software development practices for the Pharmacy Invoice Automation Platform.

The objective is to establish a consistent development approach across all modules.

# 2. Development Goals

The project shall be:

- Maintainable
- Testable
- Modular
- Scalable
- Observable
- Secure

# 5. Development Standards

Every source file shall:

- Have a single responsibility.
- Follow naming conventions.
- Be unit testable.
- Avoid duplicated logic.
- Be documented when necessary.

# 7. Quality Requirements

# 8. Acceptance Criteria

✓ Architecture is respected.
