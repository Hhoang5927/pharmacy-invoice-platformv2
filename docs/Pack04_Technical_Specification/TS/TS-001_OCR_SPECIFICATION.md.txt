# 1. Overview

## Purpose

The OCR Module converts invoice images into machine-readable text.

It is the first processing stage of the Pharmacy Invoice Automation Platform.

The OCR module is responsible only for text recognition.

It does not perform business validation or semantic understanding.

---

## Responsibilities

The OCR module shall:

- Accept invoice images and PDF files.
- Validate supported formats.
- Pre-process images for recognition.
- Extract all visible text.
- Preserve table structure where possible.
- Return confidence scores.
- Return page metadata.
- Produce standardized OCR output.

---

# 2. Scope

## Included

- PDF processing
- Image processing
- Multi-page invoices
- Vietnamese language
- English language
- Table extraction
- Confidence calculation

## Excluded

- AI extraction
- Business validation

# 7. Image Pre-processing

The OCR module should perform:

- Auto rotation
- Deskew
- Noise reduction
- Contrast enhancement
- Resolution normalization
- Blank page detection

These operations improve OCR accuracy without altering document content.

---

# 8. OCR Output

The OCR module shall return:

- Extracted text
- Page count
- Confidence score
- Processing duration
- OCR engine version
- Language detected

Output format shall be UTF-8 encoded.

---

# 9. Confidence Rules

Confidence shall be calculated:

- Per page
- Per text block
- Overall document

Confidence range

0.00 → 1.00

Low confidence documents shall be flagged for review.

---

# 10. Exception Handling

Possible failures

- Unsupported file format
- Corrupted PDF
- Empty image
- OCR engine timeout
- OCR engine unavailable

Recovery actions

- Retry
- Mark as failed
- Send to manual review
