# 1. Overview

## Purpose

The AI Extraction Module transforms OCR text into a structured business object.

The module converts unstructured text into the Core Domain defined in Pack 03.

This module does not perform business validation.

It only performs semantic extraction.

---

## Responsibilities

The module shall:

- Parse OCR output
- Identify invoice fields
- Extract supplier information
- Extract medicine information
- Extract purchase items
- Extract batch information
- Extract invoice totals
- Calculate confidence score
- Return structured data
